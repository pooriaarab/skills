# Fees and timing — BC incorporation

From the official fee schedule (corporateonline.gov.bc.ca fee_schedule.htm and
the citizen guide PDF), verified Sept 2026. A $1.50 service charge applies per
online filing where noted.

| Item | Fee | Notes |
|---|---|---|
| Name Request (standard) | $30 + $1.50 | Examiner-reviewed; current wait posted in the app banner (~7 days observed) |
| Name Request (priority) | $130 + $1.50 | Jumps the queue (~5 days observed) |
| Incorporation Application | $350 + $1.50 = **$351.50** | Credit card at File and Pay |
| Future effective date | +$100 | Up to 10 days ahead |
| Numbered company | $351.50 total | No NR needed — incorporation number becomes the name (`NNNNNNN B.C. LTD.`) |
| NR validity | 56 days | Incorporate before expiry or re-file and re-pay |
| Annual report | $43.39 + $1.50 | Recurs every year — tell the user |

## Naming rules that cost a re-file

- A named company needs a **designation**: INC. / LTD. / CORP. /
  INCORPORATED / LIMITED / CORPORATION. Brand without the suffix is fine in
  marketing — the legal name carries it.
- Structure = distinctive element + descriptive element + designation.
  `<coined> <descriptor> INC.` passes; `<coined> INC.` alone gets a structure
  warning (still submittable — the examiner decides).
- Consent words (e.g. regulated-profession terms) need a consent letter —
  a sample is downloadable in the app.
- The automated Similar Name Check is not exhaustive; the human examiner is
  the real gate.
