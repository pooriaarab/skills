# Setup

- Use a solid dark wallpaper with no motion.
- Remove animated home widgets.
- Turn Reduce Motion on.
- Set Auto-Lock to Never only for the session, then restore it.
- Turn Low Power Mode off while calibrating.
- Turn portrait lock on.
- Turn AssistiveTouch on and leave its button at the bottom-right.
- On iOS 13.4 or later, set Pointer Control size and contrast before calibration, because a size change changes the span.
- Mirror the screen to iPhone Agent.
- Keep the phone unlocked.

## Cable and radio

- A charge-only cable makes the phone a USB device, so the board never mounts.
- The phone port is the USB host.
- The adapter needs a charge port and a data port.
- The ESP32-S3 is 2.4 GHz only.

## One set

- One board, one server, one mirror name.
- A second board replaces the TCP client.
